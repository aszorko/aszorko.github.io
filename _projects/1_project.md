The Virtual Eye project investigates how to predict eye gaze and how to make practical use of these predictive models. Using both mathematical and deep learning models, we aim to create agents that can search efficiently and in a tuneable way.

I have been involved in work on generative models {%cite bhandari2025modeling %}, fixation identification {%cite orioma2026identification %}, and uncovering new biases with help from step selection methods {%cite szorkovszky2025saccade %}. Ongoing work looks into hybrid modelling, foraging (both empirically and with evolution simulations) and screening for ADHD using reading patterns.

This work is a collaboration with <a href="https://www.oslomet.no/en/about/tkd/it/ai-lab">OsloMet AI Lab</a>.
